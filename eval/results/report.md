## 关键发现

- **端到端排序最优**：`分块: 父子块 child=300`（MRR 0.988）｜最差：`分块: 固定长度(基线)`（0.902）｜差距 **+0.085**
- **单路召回对比**（Recall@5 / MRR）：向量 1.000 / 0.929　关键词 0.927 / 0.809　→ 向量更强
- ⚠️ **RRF 融合在本评测集上未带来提升**：融合后 MRR 0.909 反而低于最好的单路（向量 0.929，-0.020）。说明较弱的另一路拉低了好结果的排名。**这不代表混合检索没用** ——它在含型号/数字/专有名词的语料上价值明显（本评测集是简历，这类 token 很少），换一份设备手册类文档结论可能相反
- **链路各步增量**（MRR）：精排 +0.059，Prompt(父块) +0.024
- ⚠️ **精排分数阈值拒答在本评测集上失效**：无答案题最高分 0.995 ≥ 有答案题最低分 0.002，两类完全重叠。根因是精排模型判断的是「这段文字与查询是否相关」，而不是「这段文字能否回答问题」—— 话题相关但没答案的问题同样拿高分。**需要改为显式的「资料是否足以回答」判定**（先让 LLM 判可用性再决定是否生成），分数阈值只能作为粗筛
- **精排的收益与代价**：端到端 MRR 0.929 → 0.988（+0.059），检索 P95 增加约 89 ms
- **分块粒度对 MRR 的影响**：child=150 → 0.959，child=300 → 0.988，child=500 → 0.957
